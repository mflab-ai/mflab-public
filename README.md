# MFLab Public Downloads

Public release downloads for [MFLab](https://lab.missflash.com/), an independent software studio building thoughtful tools for moments and machines.

This repository distributes release builds for MFLab's Mac apps and provides a public place to report issues. Product source code and website content are maintained separately.

## Install

- **Memora:** Install from the App Store on iPhone or iPad running iOS or iPadOS 18 or later.
- **Mac-Monitor:** Download the DMG, open it, and drag MacMonitor.app to Applications. Requires macOS 13 or later. Available brightness and volume controls depend on your monitor's DDC/CI support and connection.
- **CLF Studio:** Download the DMG, open it, and drag CLF Studio.app to Applications. Requires macOS 14 or later on Apple Silicon. Keep an original CLF backup and review the [support guide](https://lab.missflash.com/clf-studio/support.html) before using edited copies with ListPro on iPhone.

## Releases and update history

The [MFLab Downloads release](https://github.com/mflab-ai/mflab-public/releases/tag/mflab-downloads) is the shared download channel for the current Mac installers. Each product has its own asset; choose the DMG for the app you want.

The [Releases page](https://github.com/mflab-ai/mflab-public/releases) also retains historical builds, including older tag formats. Historical release dates and tag order do not necessarily identify the current download channel. Use the product links above for current downloads and the website changelogs for user-facing release notes.

Memora is distributed through the App Store; its app download is not hosted in this repository.

Support requests are handled privately. Remove personal information from screenshots and do not attach private photos, diaries, CLF archives, passwords or signing credentials.
