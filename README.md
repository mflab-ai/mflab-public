# MFLab Public Downloads

Public release downloads for [MFLab](https://lab.missflash.com/), an independent software studio building thoughtful tools for moments and machines.

This repository distributes release builds for MFLab's Mac apps and provides a public place to report issues. Product source code and website content are maintained separately.

| --- | --- | --- | --- |

## Install

- **Memora:** Install from the App Store on iPhone or iPad running iOS or iPadOS 18 or later.
- **Mac-Monitor:** Download the DMG, open it, and drag Mac-Monitor.app to Applications. Requires macOS 13 or later. Available brightness and volume controls depend on your monitor's DDC/CI support and connection.
- **List Studio:** Download the DMG, open it, and drag List Studio.app to Applications. Requires macOS 14 or later on Apple Silicon. Keep an original CLF backup and review the [support guide](https://lab.missflash.com/list-studio/help.html) before using edited copies with ListPro on iPhone.

## Releases and update history

The [MFLab Downloads release](https://github.com/mflab-ai/mflab-public/releases/tag/mflab-downloads) is the primary download channel for current Mac installers. Each product provides its own verified DMG asset; choose the DMG for the app you want.

User-facing release notes, feature updates, and version history are maintained in each product's changelog on the MFLab website.

Memora is distributed through the App Store; its app download is not hosted in this repository.
